# PlatoonX Website

A stunning, highly-animated, single-page website for PlatoonX, an AI research startup advancing India.
This project is built using **plain HTML, CSS, and Vanilla JavaScript** for maximum performance and instant deployability to GitHub Pages.

## Project Structure
- `index.html`: The main semantic structure and content of the website.
- `assets/css/styles.css`: All styling, layout, and Stripe-inspired design tokens.
- `assets/js/script.js`: Intersection observer logic for smooth scroll-reveal animations.
- `logo/`: Contains the brand logos.
- `docs/`: Contains the original project planning, AI instructions, and design specification documents.

## Running Locally
Since this is a static site without a framework, no build steps or dependencies (`node_modules`) are required!
1. Simply double-click on `index.html` to open it in your web browser.
2. (Optional) Run a local HTTP server like `python -m http.server 8000` or use the VS Code Live Server extension for hot-reloading during development.

## Deployment
To deploy, simply commit and push these files to the `main` branch of your GitHub repository. Ensure that GitHub Pages is enabled in your repository settings (Settings -> Pages -> Source: Deploy from a branch -> `main`). GitHub will automatically host the site.
